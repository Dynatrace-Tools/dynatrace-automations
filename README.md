# Dynatrace Automations

A growing collection of **reusable tools and automations for Dynatrace** — built to kill the repetitive, click-heavy tasks that eat your day.

Part of the series: **"Tell me your Dynatrace problem, and I'll build a solution for it."**

## Tools

| Tool | What it does |
|---|---|
| [`dynatrace-extension-alert-config`](tools/dynatrace-extension-alert-config/) | Bulk-create **Davis Anomaly Detection** configs for every metric an extension ships — one command instead of clicking through the UI per metric. |

## How it's organized

Each tool lives under `tools/<tool-name>/` as a self-contained Python package with its own README. New episodes of the series are added as new folders.

## Contributing a problem

Got a Dynatrace task you're tired of doing by hand? Open an issue describing the pain — the most painful ones become the next tool.
